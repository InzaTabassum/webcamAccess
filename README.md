# Java Webcam Access with OpenCV and Swing

This is a simple beginner-friendly Java project that accesses the computer webcam using **OpenCV** and displays the live camera feed using **Swing**.

The project also supports taking photos from the live camera feed and saving them to the computer.

## Features

* Open the default webcam
* Display the live camera feed
* Take photos using a button
* Save captured photos to the computer
* Generate unique photo filenames

## Technologies Used

* **Java** — main programming language
* **OpenCV** — accesses the webcam and handles image data
* **Swing** — creates the application window and buttons
* **Maven** — manages project dependencies

## How the Program Works

```text
Start Program
     ↓
Load OpenCV
     ↓
Open Webcam
     ↓
Create Swing Window
     ↓
Capture Camera Frame
     ↓
Convert Mat to BufferedImage
     ↓
Display Frame in JLabel
     ↓
Repeat for Live Video
```

When the user clicks **Take Photo**:

```text
Click "Take Photo"
       ↓
Get Current Camera Frame
       ↓
Create Unique Filename
       ↓
Save Image as .jpg
```

## Main Components

```text
VideoCapture   → Opens and reads from the webcam

Mat            → Stores one camera frame

BufferedImage  → Java image used by Swing

ImageIcon      → Allows the image to be displayed in Swing

JLabel         → Displays the camera image

JFrame         → Main application window

JButton        → Creates the "Take Photo" button

Imgcodecs      → Saves the captured photo to a file
```

## Opening the Camera

```java
VideoCapture camera = new VideoCapture(0);
```

`0` usually means the computer's default webcam.

## Reading a Camera Frame

```java
Mat frame = new Mat();

camera.read(frame);
```

The camera image is stored inside the OpenCV `Mat`.

## Displaying the Camera

OpenCV stores camera images as a `Mat`, but Swing displays a `BufferedImage`.

The program therefore follows this process:

```text
Camera
  ↓
Mat
  ↓
byte[] pixel data
  ↓
BufferedImage
  ↓
ImageIcon
  ↓
JLabel
  ↓
Swing Window
```

Repeating this process quickly creates the live video feed.

## Taking a Photo

The application contains a button:

```text
[ Take Photo ]
```

When the button is clicked, the current OpenCV frame is saved using:

```java
Imgcodecs.imwrite(filename, frame);
```

Each photo uses a unique filename so that newer photos do not overwrite older ones.

Example:

```text
photo_1786982723456.jpg
photo_1786982731120.jpg
photo_1786982740234.jpg
```

## Ignoring Captured Photos in Git

Captured photos are generated by the application and should normally not be uploaded to GitHub.

The `.gitignore` file contains:

```gitignore
photo*.jpg
```

This allows the Java code to be pushed to GitHub without including personal camera photos.

A typical `.gitignore` for this project is:

```gitignore
.idea/
target/
*.iml
photo*.jpg
```
